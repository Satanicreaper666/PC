title: "Cybersecurity analyst"
description: "Cybersecurity analyst job description: monitor and investigate security events, test for vulnerabilities, secure cloud set-ups and support incident reporting."
industry: "Technology and SaaS"
function: "Engineering and data"
level: Senior
experience: "3–6 years"
stage: recruit
checked: 2026-11-02
summary: "This role detects, investigates and responds to security threats before they become breaches. Success means incidents caught and contained quickly, vulnerabilities fixed in order of risk, and an organisation that can meet its legal duty to report incidents."
responsibilities:
  - "Monitor SIEM (Splunk, Microsoft Sentinel or IBM QRadar) for security events; triage and escalate incidents following the SOC runbook"
  - "Conduct vulnerability assessments and penetration testing on web applications, APIs and network infrastructure"
  - "Manage vulnerability lifecycle: scan, prioritise, assign, track remediation and validate fixes with development teams"
  - "Investigate phishing attempts, social engineering incidents and malware cases; produce post-incident reports"
  - "Conduct cloud security reviews on AWS/Azure/GCP environments: IAM policy analysis, misconfiguration detection and hardening"
  - "Help the organisation report incidents on time: to CERT-In within six hours for the incident types its directions list, and, from May 2027, to the Data Protection Board and the people affected under the Digital Personal Data Protection Act, 2023"
  - "Contribute to security awareness training, phishing simulation campaigns and engineering team secure coding workshops"

  - { name: "Incident response", type: Technical, level: "Expert" }
  - { name: "Cloud security (AWS/Azure/GCP)", type: Technical, level: "Proficient" }

  - { name: "Technical report writing", type: Behavioural, level: "Proficient" }
mustHave:
  - "Has worked in a security operations centre, penetration testing or enterprise security role"
  - "Has used SIEM platforms and investigated incidents end to end"
  - "Has tested web applications and networks and written up the findings"
  - "A security certification such as CompTIA Security+, CEH or OSCP, or equivalent experience"
goodToHave:
  - "OSCP, for hands-on testing work"
  - "Knows sector security rules, such as RBI's or SEBI's cybersecurity frameworks"
  - "A cloud security certification"
interview:
  - q: "How would you investigate a suspicious log-in to a production server at 3 am from an unusual location?"
    look: "Contains the threat first if needed, gathers logs and context, checks for related activity, decides whether it's an incident, escalates and records everything for reporting and the review afterwards."
  - q: "How do you prioritise a backlog of 300 known vulnerabilities when the team can fix 20 per sprint?"
    look: "Ranks by exploitability, exposure and business impact rather than by score alone, groups fixes, uses compensating controls and agrees the remaining risk with system owners."
  - q: "What are the most common ways attackers get into SaaS companies today, and how would you defend against each?"
    look: "Names realistic routes such as phishing, stolen credentials, exposed cloud settings and vulnerable dependencies, and matches each with practical controls."
greenFlags:
  - "Has a responsible disclosure record or a published vulnerability (CVE)"
  - "Explains an attack chain they investigated, step by step"
  - "Keeps skills current through labs or capture-the-flag events"
redFlags:
  - "Only watches alerts, with no investigation or root cause work"
  - "Can't explain the difference between a vulnerability and an exploit"
  - "Doesn't know the CERT-In reporting rules or the DPDP breach duties that start in May 2027"
