Professional tax is a state tax on employment. The employer deducts it from salary and pays it to the state where the employee works. Each state sets its own slabs, and a few leave it to local bodies.

## Slabs by state

| State | Monthly salary | Professional tax |
| --- | --- | --- |
| Karnataka | Below ₹25,000 | Nil |
| | ₹25,000 and above | ₹200 a month, ₹300 in February |
| Maharashtra | Up to ₹7,500 (women: up to ₹25,000) | Nil |
| | Above ₹7,500 up to ₹10,000 (men) | ₹175 a month |
| | Above ₹10,000 (women: above ₹25,000) | ₹200 a month, ₹300 in February |
| Telangana, Andhra Pradesh | Up to ₹15,000 | Nil |
| | Above ₹15,000 up to ₹20,000 | ₹150 a month |
| | Above ₹20,000 | ₹200 a month |
| Gujarat | Up to ₹12,000 | Nil |
| | Above ₹12,000 | ₹200 a month |
| West Bengal, from October 2026 | Up to ₹20,000 | Nil |
| | Above ₹20,000 up to ₹30,000 | ₹100 a month |
| | Above ₹30,000 up to ₹50,000 | ₹140 a month |
| | Above ₹50,000 up to ₹1,00,000 | ₹170 a month |
| | Above ₹1,00,000 | ₹208 a month |

Greater Chennai Corporation charges professional tax on each half-year's salary (April to September and October to March): nil up to ₹21,000, then ₹180, ₹425, ₹930 and ₹1,025 for each band up to ₹75,000, and ₹1,250 above ₹75,000. Other Tamil Nadu local bodies set their own rates.

For 2026-27, someone in West Bengal earning ₹35,000 a month pays ₹150 a month from April to September and ₹140 a month from October to March, ₹1,740 for the year.

## States with no professional tax

Delhi, Haryana, Rajasthan, Uttar Pradesh, Uttarakhand, Himachal Pradesh and Jammu and Kashmir do not levy professional tax on salaries, as reported by payroll sources. Odisha repealed its professional tax with effect from 1 April 2026; tax for earlier months can still be recovered.

<Callout type="note" title="Not covered here">
Kerala's professional tax is set by each panchayat and municipality on half-yearly income, so one table cannot cover the state. Sources disagree on whether Goa currently levies professional tax on salaries. Several other states levy it with their own slabs. For these, check with the state's commercial tax department or the local body.
</Callout>

The tables were checked against each state's schedule, an amending Act or a reliable reproduction. For Telangana and Andhra Pradesh the official schedule could not be read, so the slabs come from payroll references; confirm them before a large payroll run.
